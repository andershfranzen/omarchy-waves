# Changelog

## 1.1.0

- **Show on lock screen**: a switch in the menu puts Waves on the lock screen. It clones Omarchy's lock screen, adds Waves to the clone, and rebuilds it after Omarchy updates so it never falls behind. Switching it off returns to the stock lock screen.
- **Update with Omarchy**: a switch in the menu updates Waves whenever you run `omarchy update`.
- `bin/waves` does the work behind both switches and can be run directly.

## 1.0.0

- First release: silk, bands, threads, aurora and saturn styles; colour, OLED black, particles, planet placement, speed, brightness, frame rate and resolution settings; presets and per-theme looks.
